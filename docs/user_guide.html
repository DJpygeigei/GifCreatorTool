2安装与启动

Windows

1
下载 GIFTool.exe从 GitHub Releases 下载最新版 GIFTool.exe
2
放到任意文件夹无需安装，双击 GIFTool.exe 直接运行
3
（可选）保持在固定目录自动更新功能会在同目录替换新版 EXE，建议不要放在只读位置
💡
工具已内置 ffmpeg，无需额外安装任何依赖，开箱即用。

macOS

1

3视频转 GIF

3.1 导入视频

支持两种方式导入视频文件：

方式操作
拖拽将视频文件直接拖拽到左侧虚线框内
浏览点击「浏览」按钮，在文件对话框中选择视频

支持格式：MP4 MOV AVI MKV WMV FLV 等主流视频格式。

📂
完整支持中文路径和中文文件名，例如「我的录像/演示视频.mp4」可以直接使用。

3.2 预览视频

视频导入后，左侧区域显示视频预览播放器，可使用以下控件操作：

视频导入后：左侧显示预览播放器，右侧显示参数面板
按钮功能
播放 / 暂停控制视频播放状态
上一帧 / 下一帧精确逐帧查看
回到开头 / 跳到结尾快速定位到视频首尾
倒放切换正向/倒向播放
音量滑块调整预览音量

3.3 选取时间范围

「选取时间范围」区域用于确定 GIF 的内容片段：

橙色滑块拖动设置开始 / 结束时间，下方显示对应时间码
1
拖动左侧橙色滑块 — 设置片段开始时间
2
拖动右侧橙色滑块 — 设置片段结束时间
3
精确输入时间码：在下方输入框直接填写，格式为 MM:SS.mmm
4
快速定位：点击「设为开始」或「设为结束」按钮，将播放器当前位置设为范围端点

选好范围后，可使用快速预览按钮确认效果：

「回到开始」跳到片段起点；「预览片段」仅播放选取区间
按钮功能
回到开始将播放器跳至片段开始时间并暂停，方便查看起始帧
预览片段从片段开始播放至结束时自动暂停，直观预览最终 GIF 效果

3.4 GIF 参数设置

设置帧率、分辨率和抖动算法
参数说明建议值
帧率 (FPS)每秒帧数。GIF 格式上限为 50fps，超过 50 自动截断15 ~ 24 fps
宽度输出 GIF 宽度（像素），高度填 -1 表示按比例自动计算480 ~ 720px
高度手动指定高度；-1 为自动等比缩放-1（自动）
抖动算法bayer：速度快、文件小；sierra2：更柔和；none：无抖动bayer（推荐）
锁定比例开启后调整宽度时高度自动等比同步建议开启

3.5 压缩选项

六种压缩模式，满足不同场景需求
模式说明适合场景
不压缩直接按设定参数转换对文件大小无要求时
保持分辨率，降低帧率保持画面清晰度，通过降低帧数减小体积画面精细度优先
保持帧率，降低分辨率保持动画流畅度，通过缩小尺寸减小体积动作流畅度优先
指定目标大小自动二分搜索，同时调整帧率和分辨率微信/邮件等有大小限制的平台
指定大小（保持分辨率）仅调整帧率以达到目标大小有尺寸要求且大小受限
指定大小（保持帧率）仅调整分辨率以达到目标大小有流畅度要求且大小受限
⚠️
选择「指定目标大小」模式时，工具会进行最多 9 次迭代搜索，耗时比普通模式略长，属正常现象。

4.2 开始 / 停止录制

1
点击「开始录制」：按钮变为「停止录制」，右侧计时器开始计时
2
操作屏幕内容：工具在后台实时捕获选定区域的画面
3
点击「停止录制」：录制停止，进入编码阶段，稍候片刻
4
录制完成：视频自动加载到预览播放器，可进行后续裁剪和参数调整
录制进行中：计时器显示已录制时长，停止按钮高亮

4.3 录制内容转 GIF

录制完成后，界面与「视频转 GIF」完全一致，可进行：

  • 使用时间范围滑块裁剪录制内容
  • 用「预览片段」按钮确认效果
  • 调整 GIF 帧率、分辨率、抖动算法
  • 选择压缩模式
  • 点击「开始转换」生成 GIF
🎯
录制帧率建议设置为 15~24 fps。GIF 格式上限 50fps，过高的录制帧率不会提升最终 GIF 质量，只会增加文件大小。

7常见问题

Q：转换出的 GIF 比视频慢很多，像慢放？

A：通常是帧率设置过低导致。尝试提高「帧率」参数（建议 15~24 fps）。如果源视频帧率是 60fps，GIF 最高只能输出 50fps，但视觉上不会有明显差异。

Q：手机录制的视频转 GIF 后画面旋转了（竖屏变横屏）？

A：工具已自动检测视频旋转元数据并修正。如果仍有异常，请确认使用的是最新版本（v1.0.2+）。

Q：提示「无法连接到 GitHub」或「rate limit exceeded」？

A：工具已内置每日缓存机制，每台电脑每天只会查询 GitHub API 一次。如处于公司内网导致无法访问，可忽略该提示，不影响工具正常使用。

Q：录制 GIF 时预览窗口不显示内容？

A：录制完成后需要等待几秒钟的编码过程，编码完成后视频会自动加载到预览窗口。若长时间没有内容，可检查磁盘剩余空间是否充足。

Q：文件路径含中文，导入或导出报错？

A：工具已通过 Windows 8.3 短路径和临时文件两层机制支持中文路径，请确认使用最新版本（v1.0.2+）。

Q：指定目标大小模式转换很慢？

A：该模式最多进行 9 次迭代搜索最优参数，耗时是普通模式的数倍，属于正常现象。如对速度有要求，建议使用「保持分辨率」或「保持帧率」模式替代。
